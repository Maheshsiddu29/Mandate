# Routing simulation report v1

`report.json` is the deterministic output of the Phase 4 seeded execution-world
simulation. Generate it with `npm run routing-simulation:generate`; ordinary
tests reproduce it and fail on drift.

All venue economics are synthetic. The base representation, market price,
contract identity and corporate-action epoch come from the recorded Phase 3
NVDA mainnet snapshot. The report is not a live-market or performance claim.
