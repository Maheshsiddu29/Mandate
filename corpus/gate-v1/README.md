# Execution-gate differential corpus, v1

A cross-implementation compatibility contract between the TypeScript side of
Mandate and the Solidity execution gate
([docs/execution-gate.md §11](../../docs/execution-gate.md#11-differential-testing-and-the-onchainoffchain-split)).

> **Status: Phase 6.** Generated by
> `packages/execution-gate/test/support/generate-gate-corpus.ts`
> (`npm run gate-corpus:generate`). `vectors.json` is committed; the package's
> `corpus.test.ts` and `npm run generated:check` fail if it drifts from the
> generator.

## What the expected values are

Every expected value is computed on the TypeScript side and nowhere else:

- mandate and candidate digests by the **kernel's** encoder (for inputs taken
  from `corpus/v2` and `corpus/mainnet-v1`) or by keccak over the exact bytes the
  gate hashes (for seeded inputs);
- structural validity by the **kernel's** decoder;
- principal-signature acceptance by the **kernel's** `verifyAuthorization`;
- everything Phase 6 adds — the market table, execution commitment, chain time,
  onchain replay and measured settlement — by the reference model in
  `packages/execution-gate/src/model.ts`.

`contracts/test/Differential.t.sol` deploys the same world at the same addresses
and asserts the Solidity gate reproduces every settlement (commitment, digests,
debit, credit, event) and every refusal (exact revert data).

## Format

```jsonc
{
  "corpusVersion": 1,
  "world": { "chainId": "46630", "gate": "0x…a7e0", "adapter": "0x…ada0", … },
  "counts": { "vectors": 215, "attempts": 222, … },
  "vectors": [
    {
      "id": "settle-003",
      "family": "recipient-substitution",
      "description": "The adapter delivers the full quantity to someone else.",
      "attempts": [
        {
          "chainId": "46630",
          "timestamp": "1800000000",
          "expected": { "settled": false, "revertData": "0xb4304839…", … },
          "script": { … },   // hand-written families only
          "input": { … }     // hand-written families only: mandate, candidate, terms, signatures
        }
      ]
    }
  ],
  "mandateEncodings": [ { "id", "source", "validity", "digest" } ],
  "candidateEncodings": [ { "id", "source", "valid", "digest" } ]
}
```

Integers are decimal strings. A vector is a *sequence* of attempts in one
world, so replay, retry-after-revert and nonce independence are expressible.
Seeded vectors list the mutations that produced them in `mutations`; their full
inputs are in the ABI form only.

## The ABI form

The same generator run writes `contracts/generated/gate-v1.abi.json`, which is
**not committed**: it carries each entry ABI-encoded exactly as the Solidity
harness decodes it, and is several megabytes of ABI padding. Run
`npm run gate-corpus:generate` before `forge test`; `npm run contracts:test`
does both. The harness fails with that instruction if the file is missing rather
than skipping.

## World

Tokens are labelled fixtures and the adapter is the `ScriptedAdapter` test
double. This corpus exercises the gate's decision, not a venue, and nothing in it
is a live observation. The signing keys are the kernel's published test keys and
secure nothing.
